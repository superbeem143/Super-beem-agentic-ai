# 🤖 SUPER BEEM AI

SUPER BEEM AI is a simple AI chatbot built using HTML, CSS, and JavaScript.

## Features

- 💬 AI Chat
- 🔊 AI Voice Reply
- 📱 Mobile Friendly
- ⚡ Fast UI
- ⌨️ Enter Key Support

## Backend Server

This project uses the following Render backend:

https://super-beem-server.onrender.com/chat

## Technologies

- HTML5
- CSS3
- JavaScript
- Render
- OpenRouter API

## How to Use

1. Open the website.
2. Type your message.
3. Click **Send** or press **Enter**.
4. Wait for the AI response.
5. Listen to the voice reply.
